#  Student Management System

A responsive web-based **Student Management System** developed to manage student records efficiently.

##  Live Demo

👉 **[View Live Project](https://devishri23.github.io/Student-Management-System/)**

> Note: The live demo link will work after the project is deployed using GitHub Pages.

##  Project Overview

The Student Management System is designed to manage student information such as:

* Student ID
* Student Name
* Course
* Email
* Marks

The project provides a simple and user-friendly interface for managing student records.

##  Features

*  Add Student
*  View Students
*  Search Student
*  Update Student
*  Delete Student
*  Student Records Table
*  Form Validation
*  Responsive Design
*  User-Friendly Interface

Used to create the structure of the Student Management System.

### CSS3

Used for styling, layout, and responsive design.

### JavaScript

Used to handle frontend interactions and student record operations.

##  Backend

The backend is developed using **Java and JDBC**.

JDBC is used to connect the Java application with the MySQL database.

##  Database

### Database

```text
studentdb
```

### Table

```text
Student
```

### Columns

| Column | Data Type |
| ------ | --------- |
| id     | INT       |
| name   | VARCHAR   |
| course | VARCHAR   |
| email  | VARCHAR   |
| marks  | DOUBLE    |

## CRUD Operations

The application supports:

* **Create** – Add a new student
* **Read** – View and search students
* **Update** – Update student details
* **Delete** – Delete student records

## Responsive Design

The application is responsive and designed to work on:

*  Desktop
*  Mobile
*  Tablet

##  Project Objective

The main objective of this project is to develop a simple and responsive student management application while gaining practical knowledge of **HTML, CSS, JavaScript, Java, JDBC, and MySQL**.
